## The review

> "One star. I bloomed once, in 2023, and he has shown that photo to every guest since. I am a stick in bark now, and the stick is doing all the work."

An orchid that flowered exactly once, back in 2023, and has lived off that single photo ever since — shown to every guest who walks in, as if the bloom were still there. What remains is a bare stick in bark, and the stick is the one doing all the work now. One star, written in sap.

## How to run

Set `MAKEFUN_OUTPUT_DIR` to the output folder, then run the entry script with Node. The script reads `entry.txt` from its own directory, checks that it is 1–279 characters, and writes the review to the output directory.
